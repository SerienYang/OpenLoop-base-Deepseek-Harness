# Product

## Register

product

## Users

Developers and technical creators who run an AI agent against local Workspaces
on macOS. They need to configure models, inspect sessions, and authorize local
resources without losing control of files or credentials.

## Product Purpose

Openloop is a local-first desktop client built on DeepSeek Harness. It gives
users a focused agent workspace while the native Host owns sensitive
credentials, Workspace authority, updates, and other privileged operations.
Success means routine agent work is fast and legible, while trust boundaries
remain visible and enforceable.

## Brand Personality

Precise, restrained, and technically confident. Copy is direct and factual.
The interface should feel like a dependable macOS work tool rather than a
marketing surface.

## Anti-references

- Marketing-style hero layouts inside the application.
- Decorative card grids, oversized type, gradients, or ornamental motion.
- Security controls that imply secret values can be revealed when they cannot.
- Custom controls that replace familiar platform behavior without a clear gain.

## Design Principles

1. Put the active workflow first and keep supporting information compact.
2. Make security state understandable without exposing protected data.
3. Use native macOS surfaces for privileged input and confirmation.
4. Prefer stable, familiar controls over decorative novelty.
5. Keep product behavior model-neutral and local-first.

## Accessibility & Inclusion

Controls must remain keyboard reachable, carry explicit accessible names, and
communicate status without relying on color alone. Text and controls must
remain readable in both light and dark themes and at supported zoom levels.
Motion is limited to state communication and must respect reduced-motion
preferences.
